# 파칭코 시뮬레이터

가상 구슬을 쏘며 못과 풍차, 워프, 투명 스테이지를 지나는 궤적을 볼 수 있는 파칭코 게임입니다. 일반 회전에서는 왼쪽 못길을 노리고, 대당첨 뒤에는 오른쪽 통로로 구슬을 보냅니다.

## 조작과 추첨

1. 왼쪽의 **구슬 빌리기**를 누르면 가상 지폐 1,000엔에 구슬 250개를 받습니다. 지급이 끝나면 보유량에 관계없이 다시 빌릴 수 있습니다.
2. 오른쪽 아래 손잡이를 돌려 발사 세기를 맞춥니다. 손잡이 고정은 기본으로 켜져 있어 손을 떼도 같은 세기로 발사합니다.
3. 액정 아래 중앙 입상구인 **헤소**를 노리세요. 일반 추첨의 대당첨 확률은 회당 1/319.7입니다. 액정 오른쪽 아래 불꽃은 진행 중인 회전과 대기 중인 추첨을 합쳐 최대 5개까지 표시합니다.
4. 리치가 걸리면 세 가지 특수 연출 중 하나가 시작됩니다. 양끝에 7이 멈추고 **PUSH**가 켜지면 기체 중앙 버튼을 누르세요. Enter와 스페이스바로도 누를 수 있습니다.

## 대당첨과 ST RUSH

대당첨 후 우타 안내가 뜨면 손잡이를 끝까지 돌리세요. 첫 당첨은 3라운드이며, 열린 어태커에 구슬이 하나 들어갈 때마다 15개를 지급합니다. 보너스가 끝난 뒤에도 우타를 유지하면 오른쪽 전동 입상구에서 다음 추첨을 받습니다.

| 초회 보너스 이후 | 진입 비율 | 최대 회전수 | 회당 당첨 확률 |
| --- | ---: | ---: | ---: |
| ST RUSH | 59% | 30회 | 1/99.4 |
| 찬스 타임 | 41% | 100회 | 1/319.7 |

두 모드 모두 재당첨하면 10라운드에서 최대 1,500개를 받고 ST RUSH 30회를 새로 시작합니다. ST RUSH에서는 진입과 재당첨 때 전용 효과음이 울리고, 마지막 5회에는 회전마다 두 번 울리는 신호음의 음높이가 올라갑니다.

## 로컬 실행과 검증

저장소 루트에서 Python 3으로 실행합니다. 게임 파일은 `dist/`에 있어 별도 빌드가 필요하지 않습니다.

```sh
python -m http.server 8000 --directory dist
```

Node.js로 스테이지 물리, 못 접촉, ST RUSH와 찬스 타임의 추첨 규칙을 각각 검증할 수 있습니다.

```sh
node tests/stage.cjs
node tests/pin-contact.cjs
node tests/rush.cjs
```

발사 세기별 구슬 경로는 `node tests/shot-trace.cjs --shots=250`으로 집계합니다. 판면 구조는 [판면과 못 배치](docs/판면-못-배치.md), 스테이지의 움직임은 [워프와 스테이지](docs/워프와-스테이지.md)에 정리되어 있습니다.
